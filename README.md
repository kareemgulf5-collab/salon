# ✂️ نظام صالون مصطفي عاشور

نظام كاشير ولوحة تحكم للصالون — HTML/JS + Firebase (Auth + Firestore)، والاستضافة على Vercel.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | تسجيل الدخول + إعداد أول مرة (حساب المالك) |
| `cashier.html` | الكاشير — فواتير، عملاء، حجز مواعيد، طباعة وصل |
| `dashboard.html` | لوحة المالك — تقارير، فواتير، مواعيد، عملاء، خدمات، حلاقين، مصروفات، مستخدمين، إعدادات |
| (كل صفحة فيها الستايل والكود جواها — مفيش فولدرات) | |
| `firestore.rules` | قواعد الأمان (بتتلصق في Firebase Console) |
| `vercel.json` | إعدادات Vercel |

## 🚀 خطوات التشغيل (بالترتيب)

> البيانات القديمة مش هتتمسح في أي خطوة. الترحيل بيقرا من `salon/data` وينسخ لمجموعات جديدة، والقديم بيفضل زي ما هو.

### 1) فعّل تسجيل الدخول بالإيميل في Firebase
Firebase Console ← مشروع **mostafa-ashour** ← **Authentication** ← **Get started** ← **Sign-in method** ← **Email/Password** ← Enable ← Save

### 2) ارفع على GitHub
- اعمل repo جديد على github.com (مثلاً `mostafa-ashour-salon`)
- ارفع محتوى الفولدر ده كله (ممكن بـ **Add file ← Upload files** وتسحب الملفات والفولدر `assets`)

### 3) اربطه بـ Vercel
- vercel.com ← **Add New ← Project** ← اختار الـ repo ← **Import**
- Framework Preset: **Other** — سيب Build Command و Output فاضيين ← **Deploy**
- هتاخد لينك زي `mostafa-ashour-salon.vercel.app`

### 4) أضف دومين Vercel في Firebase
Authentication ← **Settings** ← **Authorized domains** ← Add domain ← حط `xxxx.vercel.app`

### 5) افتح الموقع الجديد واعمل حساب المالك
- افتح لينك Vercel ← هتظهر شاشة "أول تشغيل" ← اكتب اسمك وإيميلك وباسورد
- هتدخل لوحة المالك وتظهر نافذة **ترحيل البيانات القديمة** بعدد العملاء والفواتير ← **ابدأ الترحيل**
- ⚠️ اعملها والمحل مقفول (عشان مفيش فواتير تتعمل على النظام القديم في نفس الوقت)

### 6) انشر قواعد الأمان
Firestore Database ← **Rules** ← امسح اللي موجود والصق محتوى `firestore.rules` ← **Publish**

> بعد الخطوة دي الموقع القديم (`mostafa-ashour.web.app`) هيبطل يشتغل — ودا المطلوب، عشان محدش يدخل على البيانات من غير باسورد.

### 7) اعمل حسابات الكاشير
لوحة المالك ← **المستخدمين** ← إضافة مستخدم ← صلاحية "كاشير"

## ✨ اللي اتصلح واتطور
**أمان:** Firebase Authentication حقيقي بدل الباسورد المكتوب في الكود • صلاحيات (مالك / كاشير) • Firestore Rules تمنع أي حد مش مسجل.
**البيانات:** كل فاتورة/عميل/موعد document لوحده بدل ملف واحد (مفيش ضياع فواتير لما اتنين يحفظوا مع بعض، ومفيش حد 1MB) • أرقام فواتير متسلسلة بـ transaction • التاريخ بتوقيت مصر مش UTC • الأسماء والأسعار بتتحفظ في الفاتورة (تغيير السعر أو حذف خدمة مش بيبوّظ القديم) • الحذف "ناعم" للعملاء والخدمات والحلاقين.
**الكاشير:** إضافة عميل جديد من الكاشير • عميل نقدي • بحث ذكي (أ/ا، ة/ه، أرقام عربي) بالكيبورد • اختيار الحلاق بزرار • خصم (مبلغ أو %) • طرق دفع (كاش/فودافون/إنستاباي/فيزا) • مواعيد النهارده وتحويلها لفاتورة • "لم يحضر" • حجز موعد • طباعة 80mm من غير popup + طباعة تلقائية • اختصارات (F2 / Ctrl+Enter) • يشتغل على الموبايل.
**لوحة المالك:** تقارير لأي فترة (حلاق/خدمة/طريقة دفع/يوم بيوم) + تصدير Excel • مقارنة بالشهر اللي فات • تعديل/حذف/طباعة الفواتير مع ضبط إحصائيات العميل • سجل كل عميل + واتساب • الحلاقين: راتب + عمولة % + تارجت + سلف/بونص/خصم **للشهر المختار** • المصروفات وصافي الربح • إدارة المستخدمين • بيانات المحل في الوصل • نسخة احتياطية JSON • إعادة حساب إحصائيات العملاء.
