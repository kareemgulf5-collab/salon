# ✂️ نظام صالون مصطفي عاشور

نظام كاشير ولوحة تحكم للصالون — HTML/JS + Firebase (Auth + Firestore)، والاستضافة على Vercel.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | تسجيل دخول لوحة المالك |
| `cashier.html` | الكاشير — فواتير، عملاء، حجز مواعيد، طباعة وصل |
| `dashboard.html` | لوحة المالك — تقارير، فواتير، مواعيد، عملاء، خدمات، حلاقين، مصروفات، مستخدمين، إعدادات |
| (كل صفحة فيها الستايل والكود جواها — مفيش فولدرات) | |
| `vercel.json` | إعدادات Vercel |

---

## 🚀 خطوات التشغيل

> مش محتاج تفعّل أي حاجة في Firebase. البيانات القديمة مش هتتمسح — الترحيل بيقرا من `salon/data` وينسخ، والقديم بيفضل زي ما هو.

1. ارفع الملفات كلها على repo في GitHub (Add file ← Upload files).
2. vercel.com ← Add New ← Project ← اختار الـ repo ← Framework: **Other** ← Deploy.
3. افتح لينك Vercel وادخل **بنفس إيميل وباسورد لوحة المالك القديمة** (الافتراضي `admin@salon.com` / `123456` لو مكنتش غيرتهم).
4. هتظهر نافذة **ترحيل البيانات** ← "ابدأ الترحيل" (مرة واحدة بس، والمحل مقفول).
5. الكاشير: `cashier.html` بيفتح على طول من غير دخول، زي القديم.

تغيير الإيميل والباسورد: لوحة المالك ← الإعدادات ← بيانات دخول لوحة المالك.

## ✨ اللي اتصلح واتطور
**الدخول:** زي القديم — إيميل وباسورد لوحة المالك محفوظين في Firebase وتقدر تغيرهم من الإعدادات، والكاشير بيفتح من غير دخول.
**البيانات:** كل فاتورة/عميل/موعد document لوحده بدل ملف واحد (مفيش ضياع فواتير لما اتنين يحفظوا مع بعض، ومفيش حد 1MB) • أرقام فواتير متسلسلة بـ transaction • التاريخ بتوقيت مصر مش UTC • الأسماء والأسعار بتتحفظ في الفاتورة (تغيير السعر أو حذف خدمة مش بيبوّظ القديم) • الحذف "ناعم" للعملاء والخدمات والحلاقين.
**الكاشير:** إضافة عميل جديد من الكاشير • عميل نقدي • بحث ذكي (أ/ا، ة/ه، أرقام عربي) بالكيبورد • اختيار الحلاق بزرار • خصم (مبلغ أو %) • طرق دفع (كاش/فودافون/إنستاباي/فيزا) • مواعيد النهارده وتحويلها لفاتورة • "لم يحضر" • حجز موعد • طباعة 80mm من غير popup + طباعة تلقائية • اختصارات (F2 / Ctrl+Enter) • يشتغل على الموبايل.
**لوحة المالك:** تقارير لأي فترة (حلاق/خدمة/طريقة دفع/يوم بيوم) + تصدير Excel • مقارنة بالشهر اللي فات • تعديل/حذف/طباعة الفواتير مع ضبط إحصائيات العميل • سجل كل عميل + واتساب • الحلاقين: راتب + عمولة % + تارجت + سلف/بونص/خصم **للشهر المختار** • المصروفات وصافي الربح • بيانات المحل في الوصل • نسخة احتياطية JSON • إعادة حساب إحصائيات العملاء.
